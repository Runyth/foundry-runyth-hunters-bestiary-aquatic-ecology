# Troubleshooting

If the dashboard reports that the core API is unavailable, verify dependency order and restart Foundry. If content is rejected, open Validation and Provider Diagnostics; exact paths and codes are retained.

If the dashboard opens partly off-screen, use **Configure Settings → Module Settings → Dashboard window position → Reset Position**. To restore only its default dimensions, use **Dashboard window size → Reset Size**. The circular-arrow toolbar action resets both size and position.

Window geometry is client-scoped. Each GM or player browser keeps its own layout, so resetting one client does not alter another user's dashboard.

If research Journals are absent, a GM must choose Generate Research Books. If other modules log errors, attribute them to the package path that emits them; this module does not suppress unrelated failures.
