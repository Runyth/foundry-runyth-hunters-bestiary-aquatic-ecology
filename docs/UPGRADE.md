# Upgrade Guide

Back up world data before replacement. Replace the complete module directory, restart Foundry, enable the new release, and review Provider Diagnostics. Stable content IDs are retained. Generated Journals are updated only when the GM selects generation/update. No uninstall step deletes Foundry Documents.

## 1.0.0 to 1.0.1

No data migration is required. Replace the module directory with the 1.0.1 install ZIP. Existing provider records and world Documents are unchanged. The existing client geometry setting is retained and now supports native resizing plus separate size and position resets.
