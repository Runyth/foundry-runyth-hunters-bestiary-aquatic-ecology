# Compatibility Report - Runyth Hunter's Bestiary: Aquatic Ecology 1.1.0

## Supported environment

- Foundry Virtual Tabletop v13 only, according to the module manifest.
- Native DOM and Foundry v13 ApplicationV2/HandlebarsApplicationMixin.
- No jQuery requirement and no external image hosting.
- English and German localization with exact key parity.

No live Foundry client was launched in the build environment. Compatibility claims in this release are based on manifest checks, static validation, unit/integration-style Node tests, data-schema checks, and deterministic package inspection. The included manual test plan remains required in the intended Foundry world and module stack.

## Declared dependencies

- Runyth Hunter's Bestiary 1.3.0+
- Foundry VTT 13

The uploaded authoritative baseline was a source ZIP. A corresponding installable baseline ZIP was not supplied, so source-versus-installable comparison for the old version could not be performed. The new source and install archives are cross-validated during release qualification.
